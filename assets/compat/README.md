# Совместимость и архитектура Pro

`architecture.py` — общий источник архитектуры XHTTP/REALITY для свежей установки, `-update` и восстановления. XHTTP использует `stream-up`, Unix socket и `trustedXForwardedFor: ["X-Forwarded-For"]`. Внутренние порты 7443/8443/9443 слушают только 127.0.0.1; nginx 443 принимает IPv4/IPv6 и распределяет SNI.

Существующие inbound’ы меняются точечно: XHTTP listen/порт/network/security/path/mode и известные старые значения sockopt; REALITY — внутренний listen/порт, TCP/REALITY, PROXY protocol и связь с cover на 9443; рабочие значения остаются прежними. Потерянные ключи/shortIds берутся только из сохранённого источника, новые не генерируются. Несовместимый XHTTP host исправляется; пустой host и рабочие aliases сохраняются. Clients, UUID, ключи, shortIds, enable, статистика, неизвестные поля и пользовательские записи не заменяются шаблоном. Из sockopt удаляются только совпадающие с прежним шаблоном Pro значения; отличающиеся пользовательские и новые поля сохраняются.

Принадлежность устанавливается по сохранённому ID вместе с признаками транспорта, socket/path, tag и доменами managed nginx. Порт сам по себе недостаточен. Посторонние объекты пропускаются. Закрытый manifest `/var/lib/lucx-ui-preinstall/architecture.json` хранит последние известные records/keys/hosts/memberships; удалённые объекты восстанавливаются из него либо из backup с проверенной SHA256. Данные, изменённые после последнего сохранения и затем удалённые пользователем, можно восстановить только из подходящего backup. Без сохранённых ключей скрипт не генерирует новые ключи REALITY незаметно для клиентов.

`-update y` поддерживается с v3.9.0-lucx.286. Меню предлагает обычное обновление панели с reconciliation либо reconciliation без смены версии. Оба варианта создают backup и локальный снимок для отката. При уже установленной целевой версии остаются обновление архитектуры скрипта и отмена. Native installer/updater управляет панелью и AWG; обновление архитектуры без смены панели не вызывает их. Nginx перезапускается при смене listen, иначе применяется reload.

`pro-compat.py` сохраняет прежнюю синхронизацию клиентских связей для QWDTT/CSQTT/TG Web Proxy/OpenFlux, native Clash provider, TLS подключения к панели и таймеры RKN. Режим CSQTT не меняется. Поиск nginx ограничен managed доменами/certificate/include, включая файлы без `.conf`.

`awg-bbr.py` исключает BBR/FQ из AWG performance-файла, сохраняя авторский installer/module. Существующая логика BBR панели, загрузки модулей, Certbot и ограничения логов сохранена.

Все helpers встроены в основной скрипт и backup. После изменения исходника:

```bash
python3 assets/compat/sync-embedded.py
bash -n lucx-ui-latest.sh
bash -n assets/backup/lucx-ui-backup.sh
python3 -m unittest discover -s tests
```

Прямые вызовы helpers предназначены для разработки: они не создают полный backup и не заменяют обслуживание через selector.

Сохранённые IDs/host links позволяют подогнать изменённые managed inbound под схему, сохранив имена и совместимые опции. Это миграция ранее установленной схемы, не универсальное восстановление произвольной конфигурации. После ошибки изменения откатываются, выводится рекомендация переустановки с предупреждением об удалении данных. Неизвестные поля и сторонние listeners не являются причиной отказа сами по себе.
